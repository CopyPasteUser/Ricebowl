# RiceBowl on XFCE / X11

**Current supported desktop path.** RiceBowl customizes an existing XFCE/X11
session; it does not replace the X server, XFWM4 or the system display manager.
This is separate from the [experimental Wayland desktop](WAYLAND.md).

## What you get

- Seven OS-inspired families: Windows 98, XP Luna, Windows 7, Windows 10,
  ChromeOS, Frutiger Aero and macOS-inspired styles, with several variants.
- RiceBowl Hub to discover, preview, apply and restore rices.
- Matching shell components and optional controls; the underlying XFCE
  applications and services remain available.
- Read-only health checks and explicitly confirmed updates.

## Install on Linux Mint XFCE or compatible XFCE/X11

Run from your existing graphical XFCE session:

```bash
sudo apt install -y git python3-gi python3-cairo python3-gi-cairo python3-pil gir1.2-gtk-3.0 gir1.2-wnck-3.0
git clone https://github.com/CopyPasteUser/Ricebowl.git "$HOME/RiceBowl"
cd "$HOME/RiceBowl"
bash install.sh --dry-run
bash install.sh
"$HOME/.local/bin/ricebowl"
```

The dry run previews changes. Installing alone does **not** apply a desktop
rice or enable the Wayland login session. Keep your original XFCE session
available while testing customizations.

## Daily use and recovery

Use the **RiceBowl Hub** (`ricebowl`) to choose and preview a style. The
advanced XFCE commands use the installed **`macrice`** CLI (the `ricebowl`
shortcut opens the Hub unless you select `update`, `de` or `creator`):

```bash
macrice doctor --json           # Read-only XFCE diagnostics
macrice rice plan night        # Preview the Aurora Night rice plan
macrice rice apply night       # Explicitly apply that XFCE rice
macrice rice restore           # Restore the previous XFCE rice
ricebowl update                # Check for updates (refreshes origin first)
```

The `ricebowl update` launcher defaults to a safe check with a remote refresh.
The lower-level `macrice update` CLI requires `check` or `apply`. Applying an
update is a **separate, explicit action**, not a side effect of checking. If a
rice breaks the appearance, return to your normal XFCE session and use
`macrice rice restore`.

## Scope and limitations

- These rices are **XFCE/X11** styles. Screenshots in the [X11 gallery](screenshots/current/README.md)
  were captured with virtual X11/XFWM4; hardware-specific behavior is not
  proven by those images alone.
- The [Wayland Rice Creator](WAYLAND.md#rice-creator) may be launched from X11,
  but it edits **Wayland recipes**, not the current XFCE rice.
- Cross-app window decorations depend on the application toolkit and XFWM4;
  not every third-party application can be restyled identically.
